> My calendar went to therapy because every single day it has to face another date — and not one of them has ever called it back for a second one.

## What this is

A single original groan-worthy one-liner for The One-Liner Groan-Off: a dad-joke pun so bad it makes you groan.

## Run it

```sh
python3 main.py
```

It writes the one-liner to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
